# Who Is The Spy

Jeu de déduction sociale à jouer à plusieurs sur un seul téléphone. Un ou plusieurs espions ne connaissent pas le mot secret : les autres doivent le repérer, l'espion doit le deviner sans se faire démasquer.

- Langues : français, anglais, espagnol, arabe (détection automatique).
- Fonctionne hors ligne une fois chargé (PWA).
- Aucune donnée collectée, aucune publicité. Voir `confidentialite.html`.

## Développement

Site statique, sans dépendance. Ouvrir `index.html` via un serveur local (ex. `python3 -m http.server`).
